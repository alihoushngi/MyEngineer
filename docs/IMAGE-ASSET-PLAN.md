# Image asset plan

This asset provenance/specification guide records reused client imagery and optional future assets. The current local reference root is read-only `Design/`; production copies already live under `public/images/`. Live API images remain the desktop source where supplied. Homepage categories and the six referenced service banners opt into existing client artwork on mobile. Missing-image recommendations below are not newly implemented or generated assets.

The client source banners are in `Design/assets/img/banner/`, but current
production slide artwork is not assumed byte-identical to those references.
Earlier proposed paths `hero-construction.png`, `project-engineer.png` and
`interior-design.png` are absent and must not be used as production fallbacks.
Live API images are rendered when supplied; home slide fallbacks use the three
actual files above.

About now reuses `slide 2.png` for its construction-engineer image instead of the absent `project-engineer.png`. The six referenced service pages use `public/images/services/service-banner.png` below 1024px; its SHA256 matches `Design/assets/img/banner/craiyon__Engineer.png`. Desktop retains the supplied service image. Homepage categories use existing surveying, contractor, engineeringservice, designer, license and adminastrative illustrations below 768px; the shared grid's default path is unchanged. Native responsive pictures select one image per slot and retain a direct source fallback when the existing bare-IP configuration disables generated srcsets.

Some supplied article covers are unrelated to their article subjects. Those images remain actual API data; replacing them requires appropriate catalog content rather than invented frontend assignments.

The reference celebrity/expert/testimonial demo portraits are not production
identity data. `public/images/home/join-experts.svg` is present as an existing
asset; its presence does not imply it is rendered or that protected auth should
be restyled. Historical concept boards remain in `docs/design-concepts/`.
